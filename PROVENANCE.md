# Provenance and redistribution notes

Layered Redraw source code and documentation are published under Apache-2.0 by RubyYii. This repository is an incubation source for small, reviewed contributions to the canonical VULCA Visual Control SDK; it is not itself a VULCA release.

## Bundled visual assets

- `assets/editor-preview.*.jpg` are screenshots of the repository's own local editor interface.
- `examples/canal-evening` is a geometry-authored demonstration. No source photograph is distributed.
- `examples/cat-cave-npc` is an accepted-master decomposition and delivery fixture. Its private reference photograph is intentionally excluded. The repository author authorizes redistribution of the included transformed pixel artwork, layer PNGs, masks, prompts, and ORA package under this repository's license. It is not evidence of a reproducible source-to-effect pipeline.
- `apps/scene-builder/projects/window-case/source/b2-photograph-closed-wall.png` is the repository owner's fictional-room storyboard reference for the bundled 3D fixture. Its inclusion in this repository is authorized by the repository owner; it is not a private source photograph or a claim of photoreal reconstruction.
- No external font files are bundled. Visible NPC interface lettering is rasterized into the fixture and is covered by its explicit text policy.

Do not add a photograph, font, logo, model weight, or third-party artwork without recording its source, rights basis, permitted uses, and required attribution here or in a colocated asset record.

## Optional software and models

Python packages in `requirements-raster.txt` and `requirements-depth.txt` retain their own licenses. Depth model weights are not bundled. Installing or downloading an optional model is a separate user action governed by that model's published terms; this repository does not relicense it.

## Upstream contribution boundary

Only author-owned code and rights-clean fixtures may be proposed to `vulca-org/vulca-visual-control-sdk`. Upstream changes must use VULCA's existing Artifact, `LayerInfo`, provider, tool, evidence, and release contracts. The personal repository must not become a second long-lived runtime.
