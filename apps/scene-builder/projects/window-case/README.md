# 《不存在的窗》电影沙盒交互版

这是用“灰场 · Blockout Studio”实时运行的连续3D场面，不再把房间、证物和角色拆成互不相干的展示卡。摄影机从门框进入同一个封闭房间；四个非人角色代理会移动、检查、触碰、阻断、搬运、投射、拼装和撤回，照片、录音器、杯子、床、窗与走廊都由这些行为触发。

角色使用非人形机械代理，提供电影/游戏沙盒式表演，同时不制造剧本禁止的人脸、人体或克隆声音。

## 打开项目

1. 在 `apps/scene-builder` 目录运行 `npm run dev`。
2. 在灰场右上角选择“载入”。
3. 打开 `window-that-wasnt-there.blockout.json`。
4. 切换到“剧本 / 预览”，拖动 2:46 时间线或点击播放。

唯一底板照片以原始像素纹理贴在房间内的实体相框上；它会被代理搬运，但图像内容本身不变。

## 文件

- `window-that-wasnt-there.blockout.json`：可直接载入灰场的 v3 项目，200 个 3D 对象、19 个电影机位和 720 个时间线片段，其中包含 4 个角色根节点与 2 个显式语义交互片段。
- `shot-manifest.json`：镜号、入点、电影机位路径、因果动作、30 条英文画面提示与连续空间契约。
- `source/b2-photograph-closed-wall.png`：原压缩包中的 B2 基准图，保持原始字节。
- `../../artifacts/`：本地渲染帧、联系表、视频与报告的默认输出目录；这些派生文件不会提交到 Git。

## 已锁定的制作规则

- 全片只有一个连续房间、同一张床、同一张证物桌和同一面后墙；镜头切换不会重置物体状态。
- B4 的波形由见证代理触发，并由许可守护代理从中段切断；杯子会受到冲撞并在落幅前归位。
- B7 的侧窗由摄影机与见证代理共同侧移发现；第二张床从墙后被实际推入；走廊入口在角色接近后由守护代理封闭。
- B8-01 的照片由角色搬到带缝窗旁；B8-02 的完美窗覆盖缝合状态；B8-03 由守护代理关闭生成层。
- B9 将照片、录音器、杯子和侧窗遮板恢复到进入时的位置，四个代理逐一退出，摄影机退回同一门框外。
- 三个结尾均为 8 秒。

## 角色与物品

- 四个角色是有体积、工具轨、探针和状态灯的非人形机械代理：见证（青）、改写（金）、许可守护（红）与档案（白）。
- 见证代理核验照片、追随光并触碰录音器；改写代理投射假想窗并推动空间分支；守护代理切断波形和关闭入口；档案代理搬运并归还原始证物。
- 这些角色只是权限和行为的空间化代理，不代表具体人物，也没有脸、人体或台词。
- 证物章节包含三种不等痕迹：未改动照片、标为“非原始音频”的重演波形、留存杯子。
- 床、窗、身体记得的光、断裂波形、接缝、证物板和反事实入口均分类为“物品”实体；墙、地板、房间结构线与席位舞台属于“场景”。

## 时间假设

原脚本各段标称时长相加为 2:44，但 B2 结束与 B3 开始之间留有 2 秒。预演将 B2-01 记为 18 秒：16 秒证物停留加 2 秒未分配停顿，因此总长严格为 166 秒。

## 实时预演边界

- 当前材质、机械代理和环境光是实时 Three.js 风格化表现，不是写实人物动画或离线光追。
- 原始 B2 图像已经贴入物理相框；其余墙体、布料、金属、玻璃、体积光和阴影均由实时3D材质表现。
- 确定性成片包含环境声、动作提示音和覆盖全片的 30 条英文画面提示；最终拟音、配音与写实资产仍属于后续精剪层。
- 全片回归测试会检查 166 秒内全部 4,981 个含端点的 30fps 时间样本；任何残余代理穿透或交互状态违规都会使测试失败。
- 导演时间线为手工写入的精确轨道。不要在界面中直接点击“编译时间线”，否则会用通用中文动作编译器覆盖这些精确镜头状态。

## 重建与渲染

```bash
npm run build:window-case
npm run render:window-case
npm run render:window-case:video30
```

第二条命令会重建项目、在本地启动灰场并逐镜驱动 WebGL 导演预览。第三条命令采用固定时间步输出 4,980 帧、1280×720、严格 30fps 的 VP8 WebM，并把英文画面提示烧录进成片；默认输出为 `../../artifacts/window-case-video/window-that-wasnt-there-30fps.webm`。

同一命令还会生成 `window-that-wasnt-there-30fps.simulation-package/`：166 秒场景快照、4,981 个含终点仿真采样、交互／所有权账本、碰撞报告、视频独立副本、离线 3D 回放器和全文件哈希清单。视频已经存在时可运行 `npm run package:window-case` 补建。进入包目录运行 `node verify-delivery.mjs` 验证，再运行 `node serve-replay.mjs` 检查成片与自由视角。所有派生产物保留在本地 `artifacts/`，源项目和镜头清单保持可复现。
